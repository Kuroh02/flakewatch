# Feature specs

After v1, every new feature or significant change gets its own folder here:

```
specs/
└── NNN-short-name/
    ├── spec.md    what and why  (from docs/templates/spec-template.md)
    ├── plan.md    how           (from docs/templates/plan-template.md)
    └── tasks.md   ordered tasks (from docs/templates/tasks-template.md)
```

The process is in [docs/WORKFLOW.md §3](../docs/WORKFLOW.md#3-adding-a-feature-after-v1). v1 itself is planned in `docs/SPEC.md`, `docs/PLAN.md` and `docs/TASKS.md`.
